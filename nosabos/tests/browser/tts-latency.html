TTS latency comparison

Local workerd measurements do not measure Cloudflare's edge. Use a deployed staging Worker for that comparison. This page changes no app settings and deploys nothing. Each run requests a paid OpenAI narration.

Both endpoints use the app's current player, identical text/model/voice, a new WebRTC connection, and no cache reads, recording, or re-encoding. Background connection preparation is disabled on this page. “New connection” does not mean the server or its HTTP connections are cold.

Keep this tab visible. Run several batches on the same device/network. Compare median and p95; keep the first attempt and all errors. Do not compare a prepared connection against a new connection. Authentication differences are reported, not silently disabled.

First audio = first decoded stream samples above −60 dBFS, sampled about every 20 ms. This is an approximation before speaker/output-device latency. “Server start” is a separate OpenAI event, not proof that sound has reached the speakers. HTTP includes browser CORS preflight, transit, server work, and response download.
